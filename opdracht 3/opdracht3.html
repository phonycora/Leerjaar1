Opdracht 3: HTML en CSS

1. Waarom heet de eerste pagina van een website vaak index.html?

De eerste pagina van een website heet vaak index.html, omdat servers standaard zoeken naar deze bestandsnaam als je naar een map gaat zonder expliciete pagina te noemen. Daardoor verschijnt de homepage automatisch.

2. Met welke HTML-versie werken we tegenwoordig?

Vandaag de dag werken we meestal met HTML5, de nieuwste en meest gebruikte versie van HTML.

3. Met welke CSS-versie werken we tegenwoordig?

We werken tegenwoordig meestal met CSS3, de nieuwste versie van Cascading Style Sheets.

4. Hoe kan het dat een website er net iets anders uitziet in verschillende browsers, zoals Edge, Chrome, Firefox en Opera?

Browsers gebruiken niet altijd precies dezelfde standaardinstellingen en rendering-engine. Daardoor interpreteren ze HTML en CSS iets verschillend, waardoor dezelfde website in verschillende browsers licht afwijkt.

5. Welke browser is momenteel het populairst? Vermeld ook ongeveer hoeveel RAM-geheugen deze browser gebruikt wanneer je meerdere tabbladen open hebt staan.

De populairste browser is momenteel Google Chrome. Als je meerdere tabbladen open hebt staan, gebruikt Chrome vaak ongeveer 1 tot 2 GB RAM, maar dit kan afhankelijk van het aantal tabbladen en extensies aanzienlijk hoger zijn.

6. Waar staat de afkorting HTML voor?

HTML staat voor HyperText Markup Language. Het is de standaardtaal voor het opbouwen van webpagina's.

7. Waar staat de afkorting CSS voor?

CSS staat voor Cascading Style Sheets. Het wordt gebruikt om de opmaak en stijl van een webpagina te bepalen.

8. Wat is het verschil tussen HTML en CSS?

HTML bepaalt de structuur en inhoud van een webpagina, zoals tekst, afbeeldingen en links. CSS bepaalt daarentegen de visuele stijl, zoals kleuren, lettertypen, marges en layout.

9. Wat is het doel van een webbrowser?

Het doel van een webbrowser is om webpagina's te openen, te interpreteren en visueel weer te geven. De browser leest HTML, CSS en JavaScript en toont de pagina aan de gebruiker.

10. Noem drie populaire code-editors die gebruikt worden voor webontwikkeling.

Drie populaire code-editors zijn Visual Studio Code, Sublime Text en Atom.

11. Wat is het verschil tussen een statische website en een dynamische website?

Een statische website bevat vaste inhoud die niet automatisch verandert, terwijl een dynamische website inhoud kan ophalen, aanpassen of tonen op basis van gebruikersinput, databases of serverlogica.

12. Waarom is het belangrijk om je HTML-code netjes en correct op te bouwen?

Het is belangrijk om HTML-code netjes en correct op te bouwen, omdat browsers de code dan beter begrijpen. Hierdoor werkt de pagina correct, is de structuur overzichtelijk en is de website makkelijker te onderhouden en uitbreiden.
